# Amazon Sales Analysis Dashboard | Power BI

## 📊 Project Overview

An interactive Amazon Sales Analysis Dashboard developed using Microsoft Power BI to analyze sales performance, product performance, order trends, and key business KPIs.

The project includes data cleaning, transformation, data modeling, and DAX-based analysis to generate actionable business insights.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- SQL
- Advanced Excel
- Data Modeling

## 📈 Key KPIs

- YTD Sales
- QTD Sales
- Products Sold
- Cancelled Orders
- Monthly Sales Analysis
- Weekly Sales Analysis
- Product Category Performance

## 🔍 Key Analysis

- Analyzed overall sales performance
- Analyzed monthly and weekly sales trends
- Evaluated product and category performance
- Identified top-performing products
- Performed data cleaning and transformation using Power Query
- Created calculated measures using DAX
- Built an interactive KPI-driven dashboard
